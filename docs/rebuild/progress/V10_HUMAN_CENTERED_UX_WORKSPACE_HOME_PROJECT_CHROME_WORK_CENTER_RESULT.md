## REMAINING GAP

현재 호스트에는 `docker` 실행 파일이 없다. 따라서 공식 PostgreSQL·Backend·Frontend 스택을 실행할 수 없었고, 명세가 완료 조건으로 둔 실제 로그인 사용자·실제 프로젝트의 홈, 필터, 프로젝트 헤더, 탐색기, 작업센터, 개요 시각 검증은 수행하지 못했다. 이 이유로 본 결과는 `COMPLETE`로 선언하지 않는다.

Docker 사용 환경에서 사용자 검증 문서의 절차를 완료하고 다음을 확인해야 한다.

1. 시작 전/진행 중/확인 필요/완료 프로젝트가 표시 상태와 필터에서 일치한다.
2. 작업 이력이 20건을 넘을 때 `이전 작업 더 보기`로 누적되고 빠른 목록은 1/1/3을 유지한다.
3. 1440/1024/768/390px에서 잘림, 가로 넘침, 서랍 중첩이 없다.
4. 실패·입력 필요·업데이트 필요 상태에서 원시 코드 대신 사용자 행동 문구가 보인다.
