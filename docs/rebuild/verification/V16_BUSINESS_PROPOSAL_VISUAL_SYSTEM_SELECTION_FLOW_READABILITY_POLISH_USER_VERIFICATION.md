# V16 사업안 시각 체계·재선택 흐름 사용자 검증

## 검증 상태

- 기능 자동 검증: 완료
- 사용자 시각 수용성: 검토 필요
- 권장 해상도: 1920×1080, 1440×900, 390×844

이번 문서는 인증된 실제 프로젝트에서 디자인의 체감 품질을 확인하기 위한 가이드다. 자동 테스트를 다시 수행하는 절차가 아니다.

## 1. 사업안 재선택

1. 이미 A 사업안이 선택된 프로젝트를 연다.
2. `선택 변경`을 눌러 gallery를 연다.
3. B 사업안의 `이 사업안 선택`을 누른다.

확인할 내용:

- 클릭한 B에만 `선택 중...`과 spinner가 보인다.
- 서버 응답 후 B가 `현재 선택`으로 표시된다.
- gallery가 접힌다.
- 화면이 현재 Decision 단계인 시장 분석 기준값 또는 서버가 결정한 단계로 이동한다.
- 동일한 selection record가 재사용되더라도 위 흐름이 동작한다.
- 전환이 갑자기 끊겨 보이지 않고, 모션 감소 설정에서는 즉시 전환된다.

## 2. 선택 실패

선택 요청을 실패시킬 수 있는 테스트 환경에서 B를 선택한다.

확인할 내용:

- gallery가 열린 상태를 유지한다.
- 기존 A가 계속 `현재 선택`이다.
- B가 선택 완료처럼 표시되지 않는다.
- 기준값 단계로 이동하지 않는다.
- 오류 안내가 보인다.

## 3. 사업안 gallery

사업안이 3개 이상 준비된 프로젝트에서 확인한다.

- 1920px에서도 카드가 화면 전체 폭으로 과도하게 늘어나지 않는다.
- Desktop은 최대 3열이고 각 카드의 시각 밀도가 비슷하다.
- 카드에서 사업안 이름, 한 줄 정의, 핵심 차별 정보 3개를 빠르게 읽을 수 있다.
- 현재 선택 카드는 강한 녹색 사각형보다 tonal surface·check·상태 text로 구분된다.
- 비교 toolbar는 카드보다 시각적으로 약하며 선택 수 `0/2`, `1/2`, `2/2`가 명확하다.

## 4. 버튼 체계

다음 역할이 서로 구분되는지 확인한다.

| 역할 | 대표 버튼 |
| --- | --- |
| Primary | 사업안 선택, 기준값 확인 완료, 시장 분석 시작하기 |
| Secondary | 두 사업안 비교, 선택 변경 |
| Tertiary | 세부 내용 보기, 수정, 기준값 다시 보기 |
| Icon | 비교에서 뒤로 가기, accordion 펼치기/접기 |

모든 action이 같은 흰색 직사각 outline처럼 보이거나, 과도한 pill·shadow를 사용하면 피드백이 필요하다.

## 5. 두 사업안 비교

1. 서로 다른 사업안 두 개를 비교에 추가한다.
2. `두 사업안 비교`를 누른다.

확인할 내용:

- 정확히 2개까지만 추가된다.
- Desktop에서 가로 scrollbar가 없다.
- label, A, B의 열을 자연스럽게 왕복해 읽을 수 있다.
- 전체 격자 테두리보다 행 divider가 중심이다.
- 긴 내용이 화면을 과도하게 밀어내지 않는다.
- 세부 내용 accordion이 box 안의 box처럼 무겁지 않다.
- 390px에서는 각 비교 기준 아래 A/B가 세로 pair로 보인다.

## 6. 시장 분석 기준값

처음 기준값 단계가 열렸을 때 확인한다.

- 7개 입력창이 한꺼번에 편집 상태로 노출되지 않는다.
- 각 행에서 label, 현재 기준값, 상태, `수정` action의 강도가 구분된다.
- `수정`을 누른 행만 editor가 나타난다.
- input·textarea·select가 브라우저 기본/MFC형 컨트롤처럼 튀지 않는다.
- `%`, `년`은 별도 흰 input이 아니라 값의 suffix로 보인다.
- 통화 select와 시장 규모 값이 겹치거나 surface 밖으로 넘치지 않는다.
- 긴 textarea의 읽기 폭이 지나치게 넓지 않다.

## 7. 법률·규제 결과

- 같은 법률의 조항이 하나의 법률 그룹에 묶인다.
- 조항 chip과 accordion으로 근거를 탐색할 수 있다.
- 일반 법률 정보는 neutral이고 실제 주의 항목만 경고색을 사용한다.
- 법률 surface가 카드 안 카드의 반복으로 보이지 않는다.
- 원문 링크와 조항·시행일·근거 정보가 유지된다.

## 8. 반응형 및 overflow

### 1440×900 / 1920×1080

- gallery, comparison, 기준값, 법률 영역의 폭이 각 콘텐츠 성격에 맞게 제한된다.
- 긴 form row 때문에 화면 좌우 끝을 계속 왕복하지 않는다.
- 사업안 선택 후 gallery가 compact summary로 줄어 페이지 길이가 감소한다.

### 390×844

- 페이지 전체 가로 overflow가 없다.
- gallery는 1열이다.
- 비교는 A/B vertical pair다.
- 기준값 label/value/editor가 자연스럽게 쌓인다.
- 점유율, 기간, 시장 규모, 통화 컨트롤이 겹치지 않는다.
- 중요한 primary action만 필요한 경우 full width가 된다.

## 9. 3초 질문

각 화면에서 3초 안에 다음을 답할 수 있는지 확인한다.

1. 지금 고르는 사업안은 무엇인가?
2. 두 사업안을 어떻게 비교하는가?
3. 현재 선택된 사업안은 무엇인가?
4. 지금 확인하거나 수정할 기준값은 무엇인가?
5. 다음 행동은 무엇인가?

답하기 어렵다면 화면, 해상도, 혼동한 요소를 함께 기록해 후속 디자인 조정에 사용한다.
