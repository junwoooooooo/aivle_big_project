# PHASE 6 사용자 검증

1. 새 프로젝트에서 Idea부터 Marketing까지 8단계를 한 번 연속 실행한다.
2. 각 결과의 project ID, Concept ID, Market version, BM version, snapshot ID를 기록한다.
3. 중간 Concept를 교체한 뒤 옛 downstream 결과가 stale로 숨겨지는지 확인한다.
4. TechOps 없이 Finance 준비가 성공하고, TechOps 결과는 독립적으로 유지되는지 확인한다.
5. Marketing reference artifact를 다른 프로젝트 ID로 바꿨을 때 AI 호출 전에 차단되는지 확인한다.
