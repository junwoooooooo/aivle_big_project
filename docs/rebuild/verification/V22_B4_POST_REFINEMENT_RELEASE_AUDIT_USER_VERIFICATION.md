# V22-B4 사용자 검증

다음 사용자 흐름을 실제 환경에서 짧게 확인한다.

1. Round 1 제안을 받고 proposal을 선택한다.
2. 제안을 모두 넘기고 `다른 제안 받기`를 실행한다.
3. 변경 적용 후 기존 변경을 유지한 채 다음 제안을 받는다.
4. Round 3에서 Round 4 CTA가 없는지 확인한다.
5. 법률 차단 시 finalize/next CTA가 없고 `차단된 변경 취소`만 제공되는지 확인한다.
6. 차단 변경 취소 후 이전 가설/BM 값으로 복구되고 현재 상태 확정이 가능한지 확인한다.
7. 새 Business Validation cycle에서 과거 Refinement/Final이 현재 CTA를 가리지 않는지 확인한다.
8. Desktop/mobile에서 Round 표시, proposal card, action group overflow를 확인한다.
