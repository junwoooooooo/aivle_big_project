# V14 사업 기획 흐름·실행 경험 사용자 검증

## 현재 상태

기능·자동 테스트는 통과했지만 인증 Project live visual gate는 로컬 백엔드 Flyway 오류로 **HOLD**다. 아래 검증은 백엔드가 정상 기동되는 환경에서 수행해야 한다.

## 준비

1. branch가 `full`인지 확인한다.
2. 백엔드 health가 정상인지 확인한다.
3. 실제 사용자로 로그인한다.
4. 아이디어가 없는 프로젝트, REVIEW 프로젝트, CONFIRMED 프로젝트, 사업안 RUNNING/READY 프로젝트를 준비한다.
5. 브라우저 viewport를 1440×900, 1920×1080, 390×844로 각각 확인한다.

## 1. 관리 Form

### 새 프로젝트

- `새 프로젝트`를 연다.
- 프로젝트 이름 → 사업 분야 → 간단한 설명이 위에서 아래로 이어지는지 확인한다.
- label/input이 업무 화면처럼 좌우 horizontal row가 아닌지 확인한다.
- Sheet 안에 불필요한 이중 Card가 없는지 확인한다.

### 프로젝트 설정

- 프로젝트 설정을 연다.
- 프로젝트 이름, 사업 분야, 프로젝트 설명이 compact vertical form인지 확인한다.
- 저장/취소와 삭제 영역이 기존 Sheet 위치를 유지하는지 확인한다.

## 2. Idea Review

- 상단 제목이 `아이디어 진행 가능 여부`인지 확인한다.
- `안전 확인 완료`가 기본 제목으로 남아 있지 않은지 확인한다.
- Desktop에서는 `내가 입력한 내용`과 `AI가 정리한 내용`이 40/60에 가까운 2열인지 확인한다.
- Mobile에서는 사용자 입력 → AI 정리 → 결정사항 → action 순으로 1열인지 확인한다.
- horizontal overflow가 없는지 확인한다.

### AI 정리 수정

1. `AI가 이해한 문제`를 눈에 띄는 값으로 수정한다.
2. `입력 내용으로 아이디어 확정하기`를 누른다.
3. 완료 후 같은 URL과 같은 review workspace인지 확인한다.
4. 수정한 값이 read-only로 표시되는지 확인한다.
5. 처음 입력한 문제 값은 `확정 내용 보기`에서 그대로인지 확인한다.

## 3. Idea Confirmed

- 화면 전체가 별도 Summary page로 교체되지 않는지 확인한다.
- `아이디어 정리가 완료되었습니다.` strip이 보이는지 확인한다.
- `아이디어 수정`은 왼쪽, `사업안 생성 및 검토로 이동 →`은 오른쪽인지 확인한다.
- 새로고침 후에도 같은 compact confirmed workspace인지 확인한다.
- downstream 결과가 있는 상태에서 수정하면 기존 결과가 이전 내용 기준이라는 경고가 보이는지 확인한다.

## 4. Idea Running

- 제목이 `아이디어를 정리하고 있습니다`인지 확인한다.
- 입력 내용 확인 → 진행 가능 여부 확인 → 아이디어 정리 → 확인할 내용 준비 rail이 보이는지 확인한다.
- raw JobTimeline 목록이 본문에 기본 노출되지 않는지 확인한다.
- fake percentage가 없는지 확인한다.
- reduced motion에서 current phase pulse가 사라지는지 확인한다.

## 5. 사업안 Pre-run

- 제목이 `사업안 생성 및 검토`인지 확인한다.
- 사업안 생성 → 법률·규제 검토 → 비교 및 선택 3단계가 보이는지 확인한다.
- CTA가 `사업안 생성 및 법률 검토 시작`인지 확인한다.
- `사업안 목록`, `비교` tab이 보이지 않는지 확인한다.
- `실행할 사업안을 비교하고 선택하세요` 문구가 보이지 않는지 확인한다.

## 6. 사업안 Running / Needs Input / Failed

- running에서는 업무별 phase rail이 보이고 raw 최근 event 5개 목록이 보이지 않는지 확인한다.
- 실제 reviewed 수가 있으면 그 수만 표시하고 임의 percentage를 표시하지 않는지 확인한다.
- `전체 처리 기록 보기`가 기존 Work Center Bottom Sheet를 여는지 확인한다.
- NEEDS_INPUT은 추가 정보가 필요하다는 문장과 현재 위치를 함께 표시하는지 확인한다.
- FAILED는 `사업안 생성을 완료하지 못했습니다.`와 retry/detail action을 표시하는지 확인한다.

## 7. 사업안 Ready

- 1개 준비 시 `사업안 목록`만 표시되는지 확인한다.
- 2개 이상 준비 시 `비교` tab이 나타나는지 확인한다.
- 제목이 `사업안 검토`인지 확인한다.
- 법률·규제 결과가 “문제 없음”으로 단정되지 않고 조건/주의 중심인지 확인한다.

## 8. Work Center 회귀

- Quick/Full 동시 표시가 발생하지 않는지 확인한다.
- Full Work Center는 Bottom Sheet와 body portal을 유지하는지 확인한다.
- 전체 Job history와 정확한 event, 실패 상세, retry가 그대로인지 확인한다.
- Project 본문에서 raw event를 제거했어도 Work Center의 기록은 삭제되지 않았는지 확인한다.

## 9. 3초 질문

각 화면을 연 뒤 3초 안에 다음 네 질문에 답할 수 있는지 확인한다.

1. 지금 무엇을 하는 화면인가?
2. 사용자가 해야 할 것은 무엇인가?
3. 버튼을 누르면 무엇이 일어나는가?
4. 다음에는 어디로 가는가?
