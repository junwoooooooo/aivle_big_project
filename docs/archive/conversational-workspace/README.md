# Conversational Workspace Archive

이 디렉터리는 과거 conversational workspace와 redesign 작업의 기록 보관소다.
원본 `docs/redesign/**` 문서는 R0에서 `redesign/` 하위로 이동했다.

- G0~G6 및 Runtime Fix 결과
- Conversational Workspace Spec과 구현 계획
- 과거 Codex 실행 Prompt
- Current-to-Target Map과 Decision Log
- 과거 사용자 검증 문서와 참고 자료

## 권위 경계

이 archive의 문서는 현재 제품 계약, 구현 정본, 신규 기능 요구사항이 아니다.
현재 구현은 저장소 루트 `AGENTS.md`의 우선순위와 `docs/rebuild/**`만 따른다.
archive 문서는 과거 의사결정의 배경 확인과 회귀 조사에만 사용하며, 신규 코드·Route·API·Migration의 근거로 사용하지 않는다.

archive 내용과 `docs/rebuild/**`가 충돌하면 항상 `docs/rebuild/**`가 우선한다.
