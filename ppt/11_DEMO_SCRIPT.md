## 1. 기동 절차

```powershell
Copy-Item .env.example .env      # 아래 필수 키를 채운다
docker compose up --build        # http://localhost:3000
docker compose logs -f ai-server backend
```

### 필수 환경변수 — 하나라도 없으면 compose가 뜨지 않는다

`AI_PROVIDER` · `AI_API_KEY` · `AI_MODEL` · `AI_INTERNAL_SERVICE_TOKEN` ·
`JWT_SECRET` · `POSTGRES_PASSWORD` · `MINIO_ROOT_PASSWORD` ·
**`TAVILY_API_KEY`** · **`OPENAI_API_KEY`**

## 2. ⚠ 시연 지뢰 — 미리 읽을 것

| # | 지뢰 | 증상 | 대응 |
|---|---|---|---|
| 1 | **`TAVILY_API_KEY` 누락** | compose가 아예 안 뜬다 | 시연 전날 `.env` 점검 |
| 2 | **옛 DB 볼륨** | backend가 flyway 이력 불일치로 **기동 거부** | `docker compose down -v`로 초기화 |
| 3 | **비밀번호 15자 이상** | 회원가입이 400 | 시연 계정은 미리 만들어 둔다 |
| 4 | **컨테이너 재빌드 누락** | 코드를 고쳤는데 화면이 그대로 | `--build` 없이 올리지 말 것. 프론트는 HMR이 먹는 경우가 있어 더 헷갈린다 |
| 5 | **Mock이 없다** | 키가 잘못되면 가짜 결과 없이 `AI_CONFIGURATION_INVALID`로 **실패** | 이건 설계 의도다. 다만 시연 중에 나면 그대로 멈춘다 |
| 6 | 시장조사 실행 시간 | 폴링 **90~266초** | 발표 중이면 **미리 돌려 둔 결과**를 보여주고, 실행은 별도로 시작해 둔다 |
| 7 | 유료 전 구간 미배선 | 단계 목록에 `SKIPPED / degradation: NOT_WIRED` | 질문 나오면 정직하게 답한다 (M-13) |
| 8 | 로그 인코딩 | Java=CP949, Python=UTF-8 | `Get-Content -Encoding UTF8`을 잘못 붙이면 한글이 깨져 오진 |

> **가장 안전한 시연 방식**: 미리 완주한 프로젝트 1개를 준비해 두고 화면을 이동하며 보여준다.
> 실시간 실행은 시장조사 한 곳에서만, 그것도 시작만 눌러 두고 다른 화면을 도는 사이에 끝나게 한다.

## 6. 예상 질문과 답

| 질문 | 답 |
|---|---|
| "RAG인가요?" | **아니다.** 벡터DB에 미리 넣어 두고 꺼내는 게 아니라, 질문마다 실시간으로 웹·공공API를 수집해 값에 출처를 붙인다 |
| "어떤 모델을 쓰나요? 왜 그 모델인가요?" | **모델 선택은 의도적으로 미결(OD-008)**이고, 그래서 계약을 provider-neutral로 설계했다. `AI_PROVIDER=openai\|openai-compatible` 추상화가 코드에 있다 |
| "환각은 어떻게 막나요?" | ① 출처 없는 값 0건 검사 ② AI가 돌려준 ID를 보낸 ID와 대조 ③ 결과 필드 집합 정확 일치 ④ 사용자 가설을 수집 프롬프트에 안 넣는다(자기확인 회로 차단) |
| "정확도가 몇 %인가요?" | 단일 정확도 숫자를 쓰지 않는다. **분모가 다른 4지표**로 나눠 잰다(회수율·추출률·정확도·적합률). 분모를 안 적은 비율은 우리 프로젝트에서 지표가 아니다 |
| "배포는요?" | **로컬 compose와 CI까지가 실재**다. CD·클라우드 인프라는 아직 없고 목표 문서로만 있다 |
| "성능은요?" | 응답시간 최적화는 우리 축이 아니다. 대신 **같은 자료로 성적표를 2/6 → 6/6으로** 올린 개선이 있다 (LLM 0회, 비용 0원) |
| "테스트는요?" | ai 487 · backend 469 · frontEnd 70파일. 프론트는 **부채 허용 목록에 만료일(2026-09-30)을 붙여** 관리하고 목록은 줄어들기만 한다 |
