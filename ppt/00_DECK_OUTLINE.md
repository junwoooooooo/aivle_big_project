## PIILOT과 **다르게** 가야 할 지점

| 항목 | PIILOT | 우리 |
|---|---|---|
| AI 파트의 내용 | 파인튜닝 성능 (Zero-Shot F1 0.0021 → 0.98) | **검증 체계** (측정 도구 22종 · 사전등록 · 불변식 0건). 우리는 학습 코드가 없다 |
| 성능 자랑 | 캐싱 최적화 99.86% 단축 | **"찾아놓고 버린 것을 되찾았다"** — LLM 0회 재채점으로 2/6 → 6/6 |
| 기대 효과 | 90%·70%·80%·5억 원 (출처 없음) | 근거 못 대면 **정성 서술로 낮춘다** (M-10) |
| 모델 선정 | 벤치마크 표로 2위 모델 선택 근거 제시 | **미결(OD-008)임을 그대로 말한다** — provider-neutral 계약이 설계 의도 |

## PIILOT에서 가져올 시각 문법

- 좌상단 **밑줄 제목** + 우상단 **섹션 네비게이션**(현재 위치만 진하게)
- 제목 아래 중앙에 **큰따옴표 한 줄 메시지** (그 장의 주장)
- 섹션마다 **전면 간지** — 54장을 심리적으로 쪼갠다
- 색 규칙 고정: 네이비=구조 / 형광 하이라이트=제목 키워드 / **빨강=수치·위험** / 초록=안전·개선
- 3열 또는 2×2 균등 배치. 한 장에 주장 하나
- **실제 로그·JSON을 그대로 붙인다** — 주장이 아니라 증거가 된다
- **동일 그림 반복 + 초점만 이동** (PIILOT p61–63 LangGraph 기법) → 파이프라인 그림에 적용
- 코드에 **번호 한글 주석**을 달아 설명 동선을 만든다
